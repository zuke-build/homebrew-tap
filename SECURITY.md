# Security Policy

This tap only carries `Formula/zuke.rb`, which zuke-build/zuke's release
pipeline generates; the binaries it installs are built, signed and attested
there. Security issues — in the formula, the binaries, or how either is
published — belong to that repository.

Please report them **privately**, through **"Report a vulnerability"** under
[zuke-build/zuke's Security tab](https://github.com/zuke-build/zuke/security),
as its [security policy](https://github.com/zuke-build/zuke/blob/master/SECURITY.md)
describes. Do not open a public issue.
